# 動物パズル

条件を手がかりに、動物をぴったり盤面に詰めるパズル。

公開版: https://masato-masa.github.io/animal-puzzle/

## 遊び方

- 盤面の平地マスを、動物でぴったり埋め切る（空きマスは残さない）。
- 動物には種ごとの条件がある（「ライオンのとなりに置けない」「水辺のとなりが必要」など）。
  条件は盤面の下のカードに常時表示され、満たしているかがその場で分かる。
- 動物には形がある（1マス / 横2マス / 縦2マス / 2×2）。
- 全40面、4章構成。すべて唯一解であることがテストで保証されている。

## 操作

- 動物カードをタップ → 置けるマスが光る → そのマスをタップで確定
- ドラッグでも置ける（7px 動かすとドラッグ扱い）
- 盤上の駒をタップ／ドラッグで置き直し。盤の外へ出すとトレイに戻る

## 開発

```bash
npm install
npm run dev        # http://localhost:5174
npm test           # engine のテスト含め全件
npm run typecheck
npm run deploy     # ビルドして gh-pages へ反映
```

技術構成と設計上の約束は `AGENTS.md` を見ること。
